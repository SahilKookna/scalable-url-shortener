# Scalable URL Shortener - Frontend Client

A high-performance React application serving as the user interface for the Scalable URL Shortener service.

## 🚀 Key Features

- **Instant URL Shortening**: Quick input form for generating short URLs.
- **Copy-to-Clipboard**: Built-in instant link copying for easy sharing.
- **Bloom Filter Security**: Client-side filtering check against malicious sites.
- **Responsive Interface**: Sleek UI designed with Sass styling modules.

## 💻 Tech Stack

- **React 17**
- **React Router DOM v6**
- **Axios**
- **Sass (SCSS)**
- **Bloom Filters**

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm start
```

The application will run on [http://localhost:3000](http://localhost:3000).
